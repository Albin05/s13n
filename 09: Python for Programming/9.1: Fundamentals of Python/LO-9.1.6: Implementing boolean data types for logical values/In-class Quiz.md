# Implement Boolean Data Types

## Valid boolean?
A) true
B) True
C) TRUE
D) boolean(1)

<details><summary>Answer</summary>
B - Must be capitalized: True
</details>

## How many boolean values?
A) 1
B) 2
C) Infinite
D) 3

<details><summary>Answer</summary>
B - Only True and False
</details>

## What type?
```python
x = True
```
A) int
B) str
C) bool
D) float

<details><summary>Answer</summary>
C - bool (boolean)
</details>

## Good boolean name?
A) status
B) is_active
C) active_flag
D) data_value

<details><summary>Answer</summary>
B - Sounds like yes/no question
</details>

## What's wrong?
```python
finished = "True"
```
A) Nothing
B) Should be True (no quotes)
C) Wrong capitalization
D) Variable name is invalid

<details><summary>Answer</summary>
B - Quotes make it string, not boolean
</details>
